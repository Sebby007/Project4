# 🏆 Highest Paid Athletes – Interactive Web App (Streamlit)

This project analyzes a dataset of the **highest paid athletes in the world** and presents interactive visualizations using a Streamlit web app. The dataset includes athlete demographics, nationality, sport, earnings, total annual pay, endorsements, height, and more.

Live App: https://project4-ipgt.onrender.com

---

## 🧠 Project Overview

The goal of this project is to explore earning patterns and demographic distributions among elite athletes across different sports and countries. Using exploratory data analysis (EDA), the project answers key questions such as:

- Which countries produce the highest paid athletes?  
- How do earnings differ between sports?  
- What is the gender distribution among top-earning athletes?  
- What trends can be observed visually?

These insights are displayed through an **interactive Streamlit dashboard** with filters and dynamic charts.

## 📊 Key Insights

- The dataset shows that **certain countries consistently appear among the highest earners**, suggesting strong sports industries or athlete development programs.  
- **Gender representation varies widely by sport**, with some sports showing higher male dominance in top earnings.  
- Endorsements significantly increase total annual pay for many athletes.  
- Some sports appear far more frequently in the top-paid category.
